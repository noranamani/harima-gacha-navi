## 1時間更新を導入する条件

1. 情報提供元がAPI・RSS・フィード等の機械的取得を許可していること。
2. 取得したデータの再表示・保存・リンクが利用条件に適合すること。
3. 投稿の発信時刻、取得時刻、最終成功時刻を別々に記録できること。
4. 同一投稿の重複を防止し、取得失敗時には新着表示を停止できること。
5. 連続失敗時には監視ログを残し、無制限の再試行を行わないこと。
